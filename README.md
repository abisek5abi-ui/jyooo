# Romantic Surprise 💌

Plain HTML/CSS/JS. No install needed.

## Run
Double-click `index.html`, or for a local server:
    python3 -m http.server 8000
then open http://localhost:8000

## Customise (everything is in config.js)
- Passwords (both in config.js):\n  - `realPassword` opens the real romantic website\n  - `fakePassword` opens the fake ragebait experience\n  - Any other password shows the normal error. Keep the two different.
- Photos: put 8 images in `photos/` named photo1.jpg ... photo8.jpg (or change paths) and edit captions
- Songs: `music/song1.mp3` plays on the photo album, `music/song2.mp3` plays on the love letter (titles and paths in `songs`)
- Letter: edit `letter`
